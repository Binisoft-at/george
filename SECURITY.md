# Security

Found a security or privacy problem in George? Please report it privately:
**Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting).
Please don't open a public issue for it.

What George does with data is described in [docs/HEALTH.md](docs/HEALTH.md) and in the app
(Settings → iCloud & Data → Where your data lives): workouts sync only through the user's own private
iCloud database; Apple Health numbers stay on the device; there are no George servers or accounts.
